# Studio 5000 AOI 修复总结

## 问题描述
错误：第 103 行：创建 'Parameter' (输入或输出参数必须为支持的基本 data type。) 时出错。
- RSLogix5000Content/Controller/AddOnInstructionDefinitions/AddOnInstructionDefinition[@Name="OreProdStats_3Shift_Test"]/Parameters/Parameter[@Name="Test_Message"]

## 根本原因
Studio 5000 中 **STRING 数据类型不能直接用作 AOI 参数**，因为 STRING 被认为是复杂数据类型，而 AOI 参数必须是基本数据类型。

## 解决方案
1. **将 Test_Message 参数从 STRING 改为 DINT**
   - 使用简单的数字代码代替复杂的字符串数组
   - DINT 是 Studio 5000 完全支持的基本数据类型
   - 避免了 AOI 参数不支持数组的问题

2. **同时修复 TestResult_Type 数据类型中的 Test_Message 字段**
   - 保持数据类型一致性，改为 SINT 数组（仅在内部使用）

3. **简化代码中的字符串操作**
   - 使用数字代码代替字符串消息
   - 消息代码映射：
     - 0 = 测试开始
     - 1 = 所有测试通过
     - 2 = 测试失败
     - 3 = 基础功能测试失败: 脉冲累计错误
     - 4 = 基础功能测试通过
     - 5 = 基础功能测试失败: 清除功能错误
     - 6 = 班次切换测试完成
     - 7 = 2小时时段测试完成
     - 8 = 边界条件测试完成

4. **移除不必要的循环变量**
   - 不再需要数组操作，简化代码结构

## 修改的文件
- `OreProdStats_3Shift_Test.L5X`

## 修改内容
1. **参数定义**：`Test_Message` 参数从 `STRING` 改为 `Test_Message_Code` (DINT)
2. **数据类型定义**：`TestResult_Type.Test_Message` 保持为 `SINT` 数组（内部使用）
3. **代码简化**：所有复杂的数组操作改为简单的数字代码赋值
4. **移除冗余**：删除不再需要的循环变量 `i`

## 关键发现
- **AOI 参数不支持数组类型**：Studio 5000 AOI 参数不能使用数组语法
- **最佳实践**：使用简单的 DINT 参数传递状态代码，避免复杂数据类型
- **内部vs外部**：内部可以使用复杂数据类型，但对外接口必须简化
