# FB2801 三班产量统计功能块 - 使用说明文档

## 一、功能概述

### 1.1 功能介绍

**FB2801** 是一个用于工业控制系统的产量统计功能块，主要用于根据皮带秤的实时累计产量，自动统计三个班次的产量数据。

### 1.2 核心能力

| 功能 | 描述 |
|------|------|
| **班次产量统计** | 自动统计三个班次（早班、中班、晚班）的产量 |
| **时段产量统计** | 每个班次自动划分为4个2小时时段，分别统计产量 |
| **日/月/年统计** | 自动统计今日、本月、本年产量 |
| **历史产量记录** | 自动记录昨日产量和上月产量 |
| **灵活配置** | 支持用户自定义每个班次的开始和结束时间 |
| **跨午夜支持** | 支持班次跨午夜（如17:00-01:00） |

### 1.3 适用场景

- 矿山、工厂等需要按班次统计产量的场所
- 需要实时监控各时段产量的生产管理系统
- 三班倒或多班次交替的生产环境

## 二、工作原理

### 2.1 基本原理

功能块的核心原理非常简单：

> **产量 = 当前累计产量 - 开始时刻的累计产量**

举个例子：
- 早上9:00时，皮带秤累计产量是 1000 吨（记录为起始值）
- 上午11:00时，皮带秤累计产量是 1200 吨
- 那么这2小时的产量 = 1200 - 1000 = **200吨**

### 2.2 时间判断机制

功能块通过读取PLC系统时间，判断当前处于哪个班次、哪个时段，然后自动计算相应的产量。

### 2.3 运行流程

```
开始
  │
  ▼
获取系统时间（年/月/日/时/分/秒）
  │
  ▼
计算当前时间总分钟数（小时×60+分钟）
  │
  ▼
判断当前处于哪个班次
  │
  ├── 班次1 → 计算班次1产量及各时段产量
  ├── 班次2 → 计算班次2产量及各时段产量
  └── 班次3 → 计算班次3产量及各时段产量
  │
  ▼
计算日产量、月产量、年产量
  │
  ▼
保存当前时间（供下次比较）
  │
  ▼
结束（等待下一次扫描）
```

## 三、参数说明

### 3.1 输入参数（需要设置的值）

| 参数名称 | 类型 | 默认值 | 说明 |
|----------|------|--------|------|
| `Product_Total` | REAL | - | 实时皮带秤总累计量（吨），从现场传感器读取 |
| `Initialize` | BOOL | FALSE | 初始化信号（上升沿有效），用于手动清零 |
| `Shift1_Start` | INT | 540 | 班次1开始时间（分钟），默认540=9:00 |
| `Shift1_End` | INT | 1020 | 班次1结束时间（分钟），默认1020=17:00 |
| `Shift2_Start` | INT | 1020 | 班次2开始时间（分钟），默认1020=17:00 |
| `Shift2_End` | INT | 60 | 班次2结束时间（分钟），默认60=01:00 |
| `Shift3_Start` | INT | 60 | 班次3开始时间（分钟），默认60=01:00 |
| `Shift3_End` | INT | 540 | 班次3结束时间（分钟），默认540=09:00 |

### 3.2 时间单位说明

时间参数使用**分钟**作为单位，一天共有1440分钟：

| 时间 | 分钟数 | 计算方式 |
|------|--------|----------|
| 0:00 | 0 | 0×60 |
| 1:00 | 60 | 1×60 |
| 8:00 | 480 | 8×60 |
| 9:00 | 540 | 9×60 |
| 12:00 | 720 | 12×60 |
| 17:00 | 1020 | 17×60 |
| 20:00 | 1200 | 20×60 |
| 24:00 | 1440 | 24×60 |

### 3.3 跨午夜配置

如果班次需要跨午夜（如从当天17:00到第二天01:00），配置方法如下：

```
开始时间 > 结束时间 表示跨午夜

例如：
Shift2_Start = 1020 (17:00)
Shift2_End = 60 (01:00)

这表示班次2从当天17:00开始，到第二天01:00结束。
```

### 3.4 输出参数（可以读取的值）

#### 3.4.1 班次产量

| 参数名称 | 说明 |
|----------|------|
| `Product_Shift1` | 班次1产量（早班）|
| `Product_Shift2` | 班次2产量（中班）|
| `Product_Shift3` | 班次3产量（晚班）|

#### 3.4.2 日/月/年产量

| 参数名称 | 说明 |
|----------|------|
| `Product_Day` | 今日产量 |
| `Product_Month` | 本月产量 |
| `Product_Year` | 本年产量 |
| `Product_Yesterday` | 昨日产量（每日冻结）|
| `Product_LastMonth` | 上月产量（月末冻结）|

#### 3.4.3 每两小时产量

每个班次划分为4个2小时时段：

| 参数名称 | 时段 |
|----------|------|
| `Product_Shift1_2H_1` | 班次1第一段（前2小时）|
| `Product_Shift1_2H_2` | 班次1第二段（中间2小时）|
| `Product_Shift1_2H_3` | 班次1第三段（中间2小时）|
| `Product_Shift1_2H_4` | 班次1第四段（最后时段）|
| `Product_Shift2_2H_1~4` | 班次2各时段产量 |
| `Product_Shift3_2H_1~4` | 班次3各时段产量 |

#### 3.4.4 状态输出

| 参数名称 | 说明 |
|----------|------|
| `Init_Done` | 初始化完成标志，TRUE表示可以正常工作 |

## 四、默认班次配置

### 4.1 默认时间安排

```
班次1（早班）: 09:00 - 17:00
班次2（中班）: 17:00 - 01:00（跨午夜）
班次3（晚班）: 01:00 - 09:00
```

### 4.2 时段划分

| 班次 | 时段1 | 时段2 | 时段3 | 时段4 |
|------|-------|-------|-------|-------|
| 班次1 | 09:00~11:00 | 11:00~13:00 | 13:00~15:00 | 15:00~17:00 |
| 班次2 | 17:00~19:00 | 19:00~21:00 | 21:00~23:00 | 23:00~01:00 |
| 班次3 | 01:00~03:00 | 03:00~05:00 | 05:00~07:00 | 07:00~09:00 |

### 4.3 日/月/年统计基准

- **日产量**：以班次3结束时间为基准（默认09:00）
- **月产量**：每月1日的班次3结束时间
- **年产量**：每年1月1日的班次3结束时间

## 五、使用方法

### 5.1 在Step7中创建功能块

1. 打开Step7软件
2. 创建一个新的功能块，名称为 `FB2801`
3. 将 `FB2801_3Shift_Yield.scl` 中的代码复制到功能块中
4. 创建一个背景数据块 `DB2801`，类型选择 `FB2801`

### 5.2 在主程序中调用

在OB1或其他循环组织块中调用FB2801：

```st
// 示例：调用FB2801功能块
FB2801(
    Product_Total := PIW256,       // 皮带秤累计产量输入
    Initialize := M0.0,            // 初始化按钮
    Shift1_Start := 540,           // 班次1开始：9:00
    Shift1_End := 1020,            // 班次1结束：17:00
    Shift2_Start := 1020,          // 班次2开始：17:00
    Shift2_End := 60,              // 班次2结束：01:00
    Shift3_Start := 60,            // 班次3开始：01:00
    Shift3_End := 540              // 班次3结束：09:00
);
```

### 5.3 读取输出数据

```st
// 读取班次产量
L "DB2801".Product_Shift1
T MW100        // 班次1产量

L "DB2801".Product_Shift2
T MW102        // 班次2产量

L "DB2801".Product_Shift3
T MW104        // 班次3产量

// 读取日产量
L "DB2801".Product_Day
T MW106        // 今日产量

// 读取时段产量
L "DB2801".Product_Shift1_2H_1
T MW108        // 班次1第一段产量
```

### 5.4 在HMI中显示

在HMI画面中绑定以下变量：

| 显示项 | 变量地址 |
|--------|----------|
| 班次1产量 | DB2801.DBD0 |

| 班次3产量 | DB2801.DBD8 |
| 今日产量 | DB2801.DBD12 |

| 本年产量 | DB2801.DBD20 |

## 七、注意事项

### 7.1 初始化操作

功能块启动时会自动初始化一次，将当前累计产量作为起始值。如果需要手动清零：

1. 在HMI上放置一个按钮
2. 按钮按下时触发一次上升沿（从FALSE变为TRUE）
3. 功能块会将当前累计产量作为新的起始值，所有产量输出清零

### 7.2 时间精度

- 功能块基于PLC系统时间运行，时间精度为秒级
- 班次切换检测精确到秒，确保不会遗漏切换点

### 7.3 跨午夜处理

当班次跨午夜时（开始时间 > 结束时间），功能块会自动处理跨日情况，无需额外配置。

### 7.4 产量冻结机制

- **昨日产量**：每天到达班次3结束时间时自动冻结
- **上月产量**：每月1日到达班次3结束时间时自动冻结
- 冻结后的值会保持不变，直到下一个周期

### 7.5 故障处理

如果功能块出现异常：

1. 检查 `Init_Done` 标志是否为TRUE
2. 检查 `Product_Total` 输入是否正常
3. 检查PLC系统时间是否正确
4. 检查班次时间配置是否合理

## 八、故障排查

### 8.1 产量始终为0

**原因**：初始化未完成或累计产量未变化

**解决方法**：
1. 检查 `Init_Done` 是否为TRUE
2. 检查 `Product_Total` 输入是否持续增加
3. 检查PLC系统时间是否正确

### 8.2 时段产量为0

**原因**：当前时间不在该时段范围内

**解决方法**：
1. 检查当前时间是否在该班次的时段范围内
2. 检查班次时间配置是否正确

### 8.3 班次切换异常

**原因**：时间配置不合理或跨午夜处理问题

**解决方法**：
1. 检查班次开始和结束时间配置
2. 如果跨午夜，确保开始时间 > 结束时间
